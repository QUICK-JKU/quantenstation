# Quantenstation · Herbst-/Halloween-Edition (0xA)

Statische Website für die Hands-on-Quantenstation — Sonderfassung im Herbst-/Halloween-Design
für das **0xA-Event „Quantum Computing“** am 20.10.2026 (17:00–20:00, Stufenforum im OIC,
JKU Linz; https://0xa.at/events/qc2026). Zielgruppe sind Erwachsene mit Grundwissen. Die ursprüngliche Fassung zum JKU-Jubiläum (60 Jahre, 06.10.) liegt
unverändert im Branch `original-60-jahre-quantenstation`; alles, was diese Edition optisch
vom Original unterscheidet, steht in den Abschnitten 15 und 16 von `assets/quantum.css`.
Vier Stationen plus ein FAQ, alle für das Handy gebaut, alle über
QR-Code erreichbar. Auf Tablet und Laptop bleibt das Layout eine einzelne,
hochformatige Spalte, die nur etwas breiter wird.
Kein Login, kein Build-Schritt, keine Abhängigkeiten — reines HTML, CSS und JavaScript.
